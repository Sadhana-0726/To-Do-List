# 📝 Interactive To-Do List Application

A dynamic, client-side task management application built to master DOM manipulation, event handling, and local data persistence.

🔗 **Live Demo:** :- https://sadhana-0726.github.io/To-Do-List/

## ✨ Key Features

- **Full CRUD Functionality:**
  - **Create:** Add new tasks using the input form.
  - **Read:** Render task items dynamically based on current application state.
  - **Update:** Toggle completion status with checkboxes or double-click task text to edit inline.
  - **Delete:** Remove single tasks or clear all completed tasks at once.
- **Data Persistence:** Automatically syncs state with `window.localStorage` so tasks remain saved across browser reloads.
- **Advanced Filtering:** Switch views between **All**, **Active**, and **Completed** tasks seamlessly.
- **Event Delegation:** Uses event listeners attached to parent containers for optimal dynamic performance.
- **Cheerful UI/UX:** Styled with a soft pastel gradient aesthetic and smooth transitions.

## 🛠️ Tech Stack

- **HTML5:** Semantic structure and form elements
- **CSS3:** Custom responsive layout, pastel theme, and transition effects
- **JavaScript (Vanilla ES6+):** DOM manipulation, event delegation, and LocalStorage API
